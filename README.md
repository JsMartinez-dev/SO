# SO

Repositorio para el desarrollo de proyectos y prácticas relacionados con Sistemas Operativos usando el lenguaje de programación C.

## Descripción

Este repositorio contiene código fuente, ejemplos y recursos enfocados en el aprendizaje y desarrollo de conceptos fundamentales de Sistemas Operativos. Todo el código está implementado en C, y abarca temas como manejo de procesos, gestión de memoria, sincronización, y llamadas al sistema.

## Estructura del repositorio

- `src/`: Código fuente principal del proyecto.
- `include/`: Archivos de cabecera (*.h).
- `docs/`: Documentación adicional y reportes.
- `tests/`: Pruebas y casos de estudio.
- `Makefile`: Archivo para compilar el proyecto fácilmente.

## Requisitos

- [GCC](https://gcc.gnu.org/) (Compilador de C)
- Sistema operativo compatible con POSIX (Linux recomendado)
- [Make](https://www.gnu.org/software/make/) (opcional, para facilitar la compilación)

## Compilación

Para compilar el proyecto puedes usar el siguiente comando si tienes un Makefile configurado:

```bash
make
```

O manualmente:

```bash
gcc -o ejecutable src/main.c
```

## Uso

Una vez compilado, ejecuta el programa con:

```bash
./ejecutable
```

(Sustituye ejecutable por el nombre generado por tu compilación.)
